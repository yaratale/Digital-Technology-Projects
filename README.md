# 📊 Data Architecture & Relational Database Case Study

## Business Scenario Overview (CCEA Specification)
This repository contains the architecture, relational schema, and deployment documentation for a comprehensive **Enterprise Database Solution** designed for a local business entity. 

The project focuses on creating robust data-entry workflows, reducing redundant data anomalies, and establishing secure administration privileges.

## Database Architecture & Entity Relations (ERD)
The backend system is structured using a multi-table relational schema designed to enforce **Referential Integrity**. Key structures include:
- **Primary & Foreign Key Mapping:** Strict relational constraints ensuring data consistency across transactional entities.
- **Data Validation Layer:** Implementation of input masks, validation rules, and required fields to prevent injection errors and erroneous data entry at the baseline level.

## Portfolio Upgrades (Moving Beyond School Constraints)
To elevate this project beyond standard academic criteria for corporate evaluation, the following upgrades are being implemented:
1. **SQL Optimization Matrix:** Translating basic graphical queries into raw structural SQL queries to show native database engine manipulation.
2. **Security & Access Control Lists (ACLs):** Documenting role-based user access privileges (Admin vs. Standard Operator) to mirror corporate security compliance.
